# 🌤️ Weather App

A simple, fast, and clean weather website that displays real-time weather data for any city using the OpenWeather API.

---

## 🚀 Features

- Search weather by city name
- Shows temperature, humidity, and weather conditions
- Live weather icons from OpenWeather
- Error handling for invalid cities
- Fully responsive UI
- Clean gradient theme
- No frameworks required — just HTML, CSS, JS
